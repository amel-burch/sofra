# Update the AI log

1. Open docs/AI_LOG.md. If it does not exist, create it with the heading "# AI usage log".
2. Find the section of the current milestone (e.g. "## Milestone 2"). Create it if missing.
3. Ask the student which tool and model they used, what the task was and the most important prompt.
4. Ask whether the AI was wrong: what was wrong, how they noticed and how they fixed it.
5. Propose the entry in the existing format and wait for confirmation before saving. Never invent content.
